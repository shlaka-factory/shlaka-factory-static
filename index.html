What it does

Shlaka Factory is a desktop application that solo content creators and small creator teams install on their own computer to produce 9:16 vertical short videos and publish them to their TikTok accounts.

The target audience is independent short-form creators working in educational niches — personal finance explainers, career advice channels, applied-science creators, productivity coaches — who need a local, install-once workflow instead of a multi-tool browser pipeline.

How TikTok integration works

  • The creator connects their TikTok account via TikTok Login Kit.
  • The app shows the creator's display name and avatar in a "Connected as @handle" panel so the creator can confirm the right account before any upload.
  • When the creator approves the finished video, the app calls the Content Posting API Direct Post endpoint (/v2/post/publish/video/init/) with the creator-chosen caption, privacy_level, and engagement flags. The video posts directly to the creator's TikTok feed at the creator-selected privacy level.
  • The app never auto-posts, never schedules, never reads existing TikTok content.

The same operator runs two content-vertical TikTok handles — @red_team_analysis and @redteamanalysis — under a single legal entity; the second handle is reserved for a separate content vertical. The app posts to both accounts using the same Direct Post flow described above.

Scopes requested

  • user.info.basic — display the creator's handle in the connection panel.
  • video.publish — publish the finished mp4 directly to the creator's TikTok feed via the Content Posting API Direct Post endpoint, using the creator-selected privacy level.
